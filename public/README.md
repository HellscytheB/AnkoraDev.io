# Kollektor

Kollektor es una aplicación Flutter profesional para la gestión de créditos y cobranzas, optimizada para Android moderno y compatible con Firebase y Material 3.

## 🚀 Características principales
- Estructura Android profesional y limpia
- Integración completa con Firebase (auth, Firestore, messaging)
- UI Material 3 Blackcurrant, responsiva y accesible
- Login seguro, PIN y dashboard de usuario
- Código modular y mantenible

## 📦 Stack tecnológico
- **Flutter SDK**: 3.7.0 o superior
- **Dart**: >=3.8.0
- **Firebase**: Autenticación y base de datos
- **Material Design 3**: UI adaptable
- **Java**: 21+ recomendado

## ⚙️ Instalación y build
1. Clona el repositorio:
   ```cmd
   git clone <url-del-repo>
   cd kollektor
   ```
2. Instala dependencias:
   ```cmd
   flutter pub get
   ```
3. Compila y ejecuta en Android:
   ```cmd
   flutter build apk --debug
   flutter run
   ```

- Asegúrate de tener el archivo `google-services.json` en `android/app/`.
- Si tienes errores de build, ejecuta `flutter clean` y repite los pasos.

## 🧪 Testing
- Ejecuta los tests con:
  ```cmd
  flutter test
  ```
